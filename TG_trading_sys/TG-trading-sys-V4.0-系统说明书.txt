================================================================================
一、系统概述
================================================================================

TG-trading-sys 是一套完整的 A股投资决策系统，覆盖从数据获取、估值分析、
因子筛选、择时信号、组合构建到风控监控的完整投资流程。

【设计理念】
  - 模块解耦：每个子系统独立可用，也可串联成完整管线
  - 多源降级：Tushare(付费) → mootdx(免费TCP) → 腾讯(免费HTTP)
  - 缓存优先：所有数据本地 SQLite 缓存，减少网络依赖
  - 可配置化：因子权重、风控参数、信号阈值均可调

【覆盖能力】
  ├── 数据获取    K线(日/分钟) / 财报三表 / 资金流 / 研报 / 一致预期
  ├── 估值分析    DCF两阶段 / PE-PEG / PB-ROE / 研报共识 / 情景分析
  ├── 因子筛选    19因子×4大类 + 行业中性化 + 反转/跃进/加速增长
  ├── 择时信号    均线系统 + 形态识别 + 资金面 + 事件驱动 → 聚合裁决
  ├── 组合管理    6种权重方法 + 约束验证 + 回测 + 绩效 + 监控
  ├── 风控引擎    规则链 + VaR/CVaR + 压力测试 + 绩效归因
  └── 大盘环境    5维判定 + 板块轮动 + 情绪仪表盘 + 仓位中枢

6.2 DCF 两阶段估值

  函数: dcf_value(code, wacc=None, growth_rates=None, fcf_base=None, ...) → dict

  模型: 企业价值 = Σ(FCF_t / (1+WACC)^t) + 终值/(1+WACC)^n
        股权价值 = 企业价值 - 净债务
        每股价值 = 股权价值 / 总股本

  FCF 估算优先级:
    1. 经营活动现金流净额 - 资本支出 (从现金流量表)
    2. 净利润 × (1 - 20%再投资率) (从利润表)
    3. EPS × 总股本 × 0.7 (兜底)

  安全机制:
    - WACC 与永续增长率利差不足 2% 时自动调整 WACC
    - FCF 基准异常大 (> EPS × 总股本 × 20) 时使用兜底估算
    - 终值占比 > 80% 时发出警告
    - 所有财务值统一归一化到万元

6.3 WACC 估算

  函数: estimate_wacc(code) → dict

  模型: WACC = Ke × E/(E+D) + Kd × (1-T) × D/(E+D)
  Ke = Rf + β × ERP (CAPM)

  返回: {wacc, ke, kd, beta, rf, erp, tax_rate, d_e_ratio, ...}

  股权成本 (Ke):
    - 从 stock_basic 获取市场数据
    - β 通过历史回归估算
    - 默认参数: Rf=2.8%, ERP=6.5%, 默认β=0.25

6.4 相对估值

  PE-PEG:
    —— 合理PE = EPS增速(%) × 1.0 (PEG=1标准)
    —— 合理价 = 合理PE × TTM EPS

  PB-ROE:
    —— 合理PB = (ROE - g) / (Ke - g)
    —— 合理价 = 合理PB × 每股净资产

    ROE 计算: 优先使用同花顺历史实际EPS × 总股本 / 股东权益
              (避免新浪财报累计值叠加问题)

6.5 一致预期

  函数: get_earnings_forecast(code) → dict

  优先级:
    1. 同花顺 yjycData JSON (一致预期 EPS)
    2. 东财研报 EPS 均值 (如果有的话)
    3. 历史增长率 (作为兜底)

  返回: {eps_forecast, growth_rates, cagr_3y, trailing_eps, source}

6.6 情景分析

  三档情景:
    乐观: 增长 ×1.2, 利润率 ×1.1 → 调整 WACC 降低
    中性: 基准
    悲观: 增长 ×0.8, 利润率 ×0.9 → 调整 WACC 升高

7.1 因子注册中心

  文件: TG_trading_sys/factor/factor_registry.py

  已注册: 19 个因子, 4 大类

  【价值因子 (value) — 4个】
    PE(TTM)         — 市盈率 (负向: 越低越好)
    PB              — 市净率 (负向)
    PS(TTM)         — 市销率 (负向)
    FCF 收益率       — 自由现金流/市值 (正向)

  【成长因子 (growth) — 6个】
    EPS 增速 (YoY)   — 每股收益同比增长率 (正向)
    营收增速 (YoY)    — 营业收入同比增长率 (正向)
    盈利加速度        — EPS增速的变化率 (正向)
    扭亏反转          — 上期亏损→本期盈利 (正向)
    营收跃进          — Q1营收 > 去年全年 × 30% (正向)
    加速增长          — 本期增速 > 上期增速 + 20pp (正向)

  【质量因子 (quality) — 5个】
    ROE              — 净资产收益率 (正向)
    毛利率            — 毛利率 (正向)
    资产负债率         — 负债率 (负向)
    现金流质量         — 经营现金流/净利润 (正向)
    ROE 稳定性        — ROE 5年标准差 (负向: 越稳定越好)

  【动量因子 (momentum) — 4个】
    20日动量          — 20日涨跌幅 (正向)
    60日动量          — 60日涨跌幅 (正向)
    量能动量          — 成交量变化趋势 (正向)
    换手率            — 日均换手率 (正向，适度)

7.2 标准化管线

  文件: TG_trading_sys/factor/standardization.py

  三阶段处理:
    1. 缩尾 (Winsorize)       — 默认 1%/99% 分位截断
    2. Z-score 标准化         — (x - mean) / std
    3. 行业中性化 (可选)       — 在每个行业内分别标准化，消除行业偏差

7.3 复合打分

  文件: TG_trading_sys/factor/composite.py

  综合评分 = Σ(标准化因子值 × 因子方向 × 大类权重 × 单因子权重)

  - 大类权重: 来自 Config.FACTOR_WEIGHTS
  - 单因子权重: 来自因子注册的 default_weight

九、组合管理 (portfolio/)

9.1 组合构建

  函数: build_portfolio(codes, method="equal_weight", ...) → dict

  【6种权重方法】

    1. equal_weight         — 等权分配 (1/n)
    2. market_cap           — 市值加权 (市值大的权重高)
    3. inv_volatility       — 波动率倒数加权 (低波高配)
    4. risk_parity          — 风险平价 (每只标的贡献相同风险)
       算法: 迭代法 → w_i ∝ 1/σ_i → 调整至各标的 RC 均等
    5. min_variance         — 最小方差组合
       算法: 闭式解 w = Σ⁻¹1 / (1ᵀΣ⁻¹1) → 约束截断
    6. max_diversification  — 最大分散度
       算法: w ∝ (1/σ) × 去相关因子 (1/平均相关性)

  【约束验证】
    支持: 单票上限 / 行业上限 / 流动性下限 / 集中度上限

  返回:
    {
      "name": "portfolio_20260728_1642",
      "method": "risk_parity",
      "holdings": [{code, name, weight, price, market_cap_yi, sector, pe_ttm, pb}, ...],
      "weights": pd.Series,
      "validation": {"passed": True/False, "violations": [...], "warnings": [...]},
      "stats": {"n_stocks": 10, "n_sectors": 5, "max_weight": 0.15, "top3_weight": 0.35},
    }

  【独立函数】
    optimize_weights(returns, method) → pd.Series

10.1 风控规则链

  文件: TG_trading_sys/risk/rules_engine.py

  engine = RiskEngine(market_regime="neutral")

  【内置规则】

    硬阻止 (block):

      - 组合 Beta 过高
      - 流动性风险 (换手率过低)

    牛市中仓位上限更宽松，熊市中更严格:
      bull:          总仓位 ≤ 80%
      neutral_bull: 总仓位 ≤ 60%
      neutral:       总仓位 ≤ 50%
      neutral_bear: 总仓位 ≤ 30%
      bear:          总仓位 ≤ 20%

  engine.check(context) → RiskCheckResult

    - violations: [{rule, level, message}, ...]
    - warnings: [{rule, level, message}, ...]

10.2 VaR / CVaR 风险度量

  文件: TG_trading_sys/risk/var.py

  【三种方法】

    1. 历史模拟法 (Historical VaR)
       — 直接用历史收益率的百分位

    2. 参数法 (Parametric VaR)
       — 假设正态分布，VaR = μ + σ × z_α

    3. 蒙特卡洛法 (Monte Carlo VaR)
       — 基于协方差矩阵的 Cholesky 分解模拟

  【核心函数】

    calc_var(returns, method="historical", confidence=0.95) → dict
      返回: {var, cvar, confidence, var_pct, detail}

    calc_cvar(returns, confidence=0.95) → float
      CVaR = 超过 VaR 的平均损失

    portfolio_var_report(returns, weights, confidence=0.95) → dict
      组合级别: 各方法 VaR + 边际 VaR + 成分 VaR

    var_backtest(returns, var_values, confidence=0.95) → dict
      Kupiec 检验: 实际突破率 vs 预期突破率

11.1 大盘状态判定 (5维模型)

  文件: TG_trading_sys/market/regime.py

  覆盖六大指数: 上证/深证/沪深300/创业板/科创50/中证500

  detect_regime(df) → dict

  【5个判定维度 (各25分，共125→归一化100)】

    1. 均线排列 (多头/空头/缠绕)              25分
    2. 价格动量 (涨跌幅 + 均线斜率)             25分
    3. 波动率环境 (低波稳健/高波异常)           25分
    4. 成交量趋势 (放量进攻/缩量防守)           25分
    5. 极端事件/反转信号 (V型反转/假突破)        25分

  【状态分类】
    - 牛市 (≥70分): 多头排列 + 正动量 + 放量
    - 震荡偏多 (55-69): 小多头或横盘偏强
    - 震荡 (40-54): 均线缠绕 + 方向不明
    - 震荡偏空 (25-39): 小空头或横盘偏弱
    - 熊市 (<25分): 空头排列 + 负动量 + 缩量

  【转换信号】
    - 震荡→牛市确认: 价格突破MA20 + 放量
    - 牛市→震荡衰竭: 动能减弱 + 评分下降
    - 震荡→熊市确认: 价格跌破MA20 + 死叉确认

11.2 情绪仪表盘 (7维)

  综合衡量市场情绪:
    1. 涨跌家数比 (AD Ratio)
    2. 涨停/跌停比 (Limit Ratio)
    3. 北向资金净流入 (Northbound Flow)
    4. 两融余额变化 (Margin Balance)
    5. 成交量/20日均量比 (Volume Ratio)
    6. 新高/新低比 (NHNL Ratio)
    7. VIX 类波动率指数 (Implied Vol)

  评分范围: 0-100
    - 0-25: 恐惧 (逆向买入信号)
    - 25-45: 偏恐惧
    - 45-55: 中性
    - 55-75: 偏贪婪
    - 75-100: 贪婪 (逆向卖出信号)

11.3 板块轮动

  文件: TG_trading_sys/market/rotation.py

  sector_rotation() → dict

  按东财行业分类分析板块强弱:
    - 最强/最弱板块识别
    - 四类风格: 周期型 / 成长型 / 防守型 / 题材型
    - 轮动阶段判断:
        • 成长领涨 → 风险偏好提升，进攻阶段
        • 防守领涨 → 避险情绪，防御阶段
        • 周期领涨 → 经济复苏预期
        • 题材轮动 → 结构性行情

  注意: 依赖东财 get_sector_ranking，大陆住宅IP可能被风控

11.4 仓位中枢建议

  文件: TG_trading_sys/market/position_guide.py

  综合大盘状态 + 市场情绪 → 仓位建议:
    - 牛市 + 贪婪:  总仓位 70% (进攻42% + 防守21%)
    - 熊市 + 恐惧:  总仓位 12% (进攻2% + 防守9%)
    - 牛市 + 恐慌:  总仓位 76% (逆向加仓)
    - 震荡 + 中性:  总仓位 30% (均衡)

十五、已知问题与限制
================================================================================

1. 【东财API风控】 涨停池/跌停池/涨跌家数/北向资金/两融余额等实时数据
   在大陆住宅IP下间歇被风控 (HTTP 000)，情绪仪表盘依赖默认值。
   影响: 板块轮动、情绪仪表盘、研报目标价

2. 【DCF 终值占比偏高】 茅台终值占比 ~90%，超过80%警告线。
   原因: WACC偏低 (3.95%→已调整至5.26%) + FCF基数需要调优。
   影响: DCF每股估值偏低 (375 vs 预期 ~1500)

3. 【东财研报API静默失败】 get_research_targets 当前返回0条记录。
   端点可能已变更或本地IP被限。影响: 估值报告中"研报均价"权重无法使用

4. 【VPA模块数据源】 已升级为 Tushare-first，指数K线已正常。
   但资金流数据对指数不可用 (无 moneyflow 接口)

5. 【分钟K线】 仅 mootdx 支持，Tushare Pro 不支持分钟级 index_daily

6. 【回测引擎】 vibe-trading-repo 桥接可用但需完整安装依赖 (pyfolio/zipline等)

7. 【单因子计算】 需要 DataCache 实例初始化 (当前仅smoke test中报warning)

8. 【stock_basic 表结构】 缺少 price/pe_ttm/pb/mcap_yi 列，
   实时价格在 get_stock_basic 时动态获取腾讯行情合并 (临时方案)
